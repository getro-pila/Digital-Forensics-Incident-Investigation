# Evidence Quality, Scope & Publication Decisions

## Source inventory

- `NOS210_Introduction_to_Autopsy.docx`: lab instructions and illustrative screenshots, not independent completion evidence.
- `NOS210_Data_Carving_Autopsy.docx`: Rhino exercise walkthrough and illustrative screenshots, not independent completion evidence.
- `Getro_NOS210_WTR26_CASE3.docx`: Arson lab instructions, with no embedded screenshots.
- `Pila_Getro_WorkplaceDrama_PartC_Report(1).pdf`: student-authored report with findings, methodology, custody table, timeline, and three screenshot exhibits.

## Unresolved inconsistencies

1. **Image identifier:** The Workplace assignment names `WorkPlace.E01`; the completed report states `LoneWolf.E01`.
2. **Custody dates:** The report cover says March 14, 2026, and its narrative references March 2026, but custody table entries contain March 2028. No date is silently substituted.
3. **Hash validation:** The report says an MD5 hash was generated for its PDF, but no matching independently checked hash value is supplied in this portfolio.
4. **Evidence classification:** Instructional screenshots from classroom worksheets are not presented as the student's own captures.
5. **Timeline interpretation:** File timestamps are reported as an activity window, not independently established boot/shutdown events.

## Responsible public release

This repository excludes source disk images, student identifiers in workstation paths, original unredacted PDFs, and potentially sensitive content. Three exhibit preview images are derived from the student's submitted report; verify they are acceptable to publish before making the repository public. No attempt has been made to reconstruct missing artifacts or create artificial screenshots.
