# Case 02 — Rhino USB Image & Deleted-File Recovery

**Objective:** Examine a fictional USB-image training scenario and identify the location of a missing hard drive by recovering and reviewing a deleted diary document.

**Assigned evidence:** `rhino.zip` (containing `USB.dd` and supporting files, per lab sheet).

**Assignment workflow:** Compute an MD5 hash of the archive → extract it → create **Rhino Case** in Autopsy → ingest `USB.dd` → review Deleted Files → sort by MIME type → extract an `application/msword` document → inspect the recovered diary for the answer.

**Forensic concepts:** File carving and recovery, deleted-file analysis, file type identification, exported artifacts, and traceable interpretation.

**Evidence status:** The provided lab sheet contains a walkthrough and illustrative figures, but no separate completed student evidence. The missing hard-drive location is **not claimed as independently recovered** here.

**Publication rule:** Keep recovered diary contents and classroom-provided image files out of the public repository.
